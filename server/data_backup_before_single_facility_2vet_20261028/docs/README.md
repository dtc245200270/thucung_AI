# Tài liệu Hỏi Đáp & Chăm sóc Thú cưng

Thư mục này chứa các tài liệu dạng văn bản (text) để AI đọc và trả lời người dùng.
- AI sẽ tự động đọc tất cả các file \`.txt\` trong thư mục này.
- **Cách thêm/sửa nội dung**: Bạn chỉ cần tạo hoặc chỉnh sửa các file \`.txt\`. Mỗi file nên chứa từng đoạn thông tin hoặc từng cặp Câu hỏi - Trả lời (FAQ). 
- Các câu hỏi từ người dùng sẽ được tìm kiếm theo từ khóa trong các file này. Nếu tìm thấy, AI sẽ dựa vào đó để trả lời. Nếu không tìm thấy, AI sẽ báo chưa có dữ liệu.

Ví dụ tạo file \`faq.txt\`:
\`\`\`
Hỏi: Lịch tiêm phòng cho chó con như thế nào?
Đáp: Tiêm mũi 1 lúc 6-8 tuần tuổi, mũi 2 lúc 9-11 tuần, mũi 3 lúc 12-14 tuần tuổi.
\`\`\`
